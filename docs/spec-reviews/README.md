# Spec reviews

Reviews of NFHN against published specifications. Unlike
[`docs/api-proposals/`](../api-proposals/README.md), which proposes browser APIs we could adopt,
these documents start from an external spec and record a verdict per requirement: what we already
satisfy, what we changed, and what we are deliberately not doing.

A "not applicable" verdict is a result, not a gap. Recording why is the point — it stops the same
spec being re-litigated at the next review.
